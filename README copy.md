# موقع جمعية إعلامنا — نسخة التفاعل والحركة

مشروع **React + TypeScript + Vite** عربي، RTL ومتجاوب، مطابق للهوية البصرية المرفقة لجمعية إعلامنا.

## ما تغير في هذه النسخة

- أزيلت **الحلقات الدوارة** بالكامل من الصفحة الرئيسية، واستُبدلت بمشهد إعلامي متعدد الطبقات مبني على صور دليل الهوية، مع رمز إعلامنا الذي يتجمع تلقائيًا من جهتين وموجات صوتية متحركة.
- حُفظ **الـ Navbar العلوي** وشعار الجمعية. شعار وزارة الإعلام الخارجي له عرض نصي بديل في حال تعذّر تحميل صورته؛ يلزم اعتماد ملف الشعار النهائي قبل النشر.
- أضيف **مسار تنقل يساري تفاعلي** بدون خلفية بيضاء خلف الشعار: يتحرك رمز إعلامنا مع تقدم تمرير الصفحة، يتغير رقم الفصل واسم القسم، وتظهر أسماء الأقسام عند التركيز أو المرور على المؤشرات.
- أضيف قسم **الممكّنون** بخمس جهات: المركز الوطني لتنمية القطاع غير الربحي، وزارة الإعلام، هيئة تنظيم الإعلام، وزارة الموارد البشرية والتنمية الاجتماعية، مجلس الجمعيات.
- قُسم **الشركاء** إلى قطاعين فقط: الخاص وغير الربحي. أسماء وشعارات الشركاء مساحات انتظار إلى حين توفير الملفات المعتمدة.
- الأقسام الأخرى: نبذة، الأهداف الستة، الرؤية، الرسالة، البرامج، المبادرات، الحوكمة (الترخيص، المجلس، العمومية، اللائحة)، المركز الإعلامي، أرقام التواصل.
- بقي تأثير الكتابة العربية المتدرّج، وحركات دخول العناصر عند التمرير ودعم `prefers-reduced-motion`.

## المعاينة المباشرة

افتح `Ealamna_Interactive_Preview.html` في متصفحك؛ هذا **ملف مستقل تمامًا** يتضمن الصور داخله ويعمل دون اتصال إنترنت أو npm. يتضمن تفاعل التنقل والتبويبات وأثر الكتابة. بعض روابط الجهات الخارجية تتطلب اتصالًا بالإنترنت.

## تشغيل مشروع React الأصلي

يحتاج Node.js حديثًا، ومع أول تثبيت يحتاج الوصول إلى مستودع حزم npm:

```bash
npm install
npm run dev
```

ثم افتح الرابط المحلي الذي يظهر في نافذة الأوامر.

لبناء النسخة النهائية:

```bash
npm run build
npm run preview
```

## أهم الملفات

- `src/App.tsx` — الهيكل والتفاعلات والشريط الجانبي.
- `src/styles.css` — الهوية والحركات والواجهة.
- `src/data/content.ts` — النصوص والجهات وروابط الأقسام.
- `public/assets/` — صور وشعار إعلامنا من المواد المرفقة.
- `Ealamna_Interactive_Preview.html` — المعاينة المستقلة مع الأصول مدمجة.

## تنبيه النشر

قائمة الممكّنين أدخلت بناء على الأسماء التي قدمتها الجمعية، ولا تُعد الشعارات أو العلاقات الرسمية موثقة من ملفات التصميم. يجب التأكد من اعتماد الشعارات والشراكات والروابط قبل نشر الموقع رسميًا. الصور في الصفحة الرئيسية هي صور من دليل الهوية، وتُستبدل بالصور النهائية عند توفرها.
